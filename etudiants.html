Comment ça marche

Ça passe par l’école, et c’est tout.

1 · L’école demande

Un responsable, un enseignant référent ou le bureau des étudiants remplit la demande ci-dessous.

2 · EFA envoie un code

Un code pour l’école, valable toute l’année scolaire, que l’école diffuse à ses étudiants.

3 · L’étudiant active

Il entre le code ici ou dans son portefeuille EFA : les accès s’ouvrent sur son téléphone.

Pour une école

Demander l’accès pour mon école

EFA vérifie la demande, puis envoie le code à l’adresse indiquée, en général sous 48 h. Une école peut aussi ouvrir un programme complet avec comptes et suivi : Pour les organisations.

Nos règles

Simple, et honnête.

  • Le code vient de l’école. EFA ne délivre pas de pass sur simple déclaration : la demande passe par un responsable, un enseignant ou le bureau des étudiants.
  • Une année scolaire. Le code est valable jusqu’au 31 juillet, puis l’école le renouvelle en un message.
  • Des contenus, pas de l’argent. Les crédits étudiants ouvrent des ateliers ; ils ne se convertissent jamais en argent.
  • Aucun gain promis. EFA apprend à décider avec ses propres chiffres ; elle ne vend aucun produit financier.
